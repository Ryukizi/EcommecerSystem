# 🛒 E-commerce

Projeto de **e-commerce desenvolvido para fins de estudo e aprimoramento em desenvolvimento web**, utilizando tecnologias do ecossistema .NET.

A aplicação está sendo construída com foco em uma arquitetura organizada e escalável, explorando conceitos de **desenvolvimento backend, APIs, autenticação, banco de dados e integração entre diferentes tecnologias**.

> 🚧 **Status: Em desenvolvimento**
>
> O desenvolvimento do projeto está temporariamente pausado. A última etapa iniciada foi a implementação do sistema de **autenticação utilizando JWT (JSON Web Token)**.

## 🛠️ Tecnologias utilizadas

* **C#**
* **ASP.NET Core**
* **Blazor**
* **HTML5**
* **CSS3**
* **Bootstrap**
* **Supabase**
* **REST API**
* **JWT (JSON Web Token)**

## 📌 Funcionalidades

Entre as funcionalidades planejadas e em desenvolvimento estão:

* Cadastro de usuários
* Login e autenticação
* Recuperação de acesso
* Catálogo de produtos
* Busca de produtos
* Carrinho de compras
* Persistência de sessão
* Controle de permissões através de **RBAC**
* Integração com API de cálculo de frete
* Integração com gateway de pagamento
* Autenticação baseada em **JWT**
* Gerenciamento de usuários e produtos

## 🔐 Autenticação

A implementação atual do projeto está avançando para a utilização de **JWT (JSON Web Token)** como mecanismo de autenticação.

O objetivo é utilizar tokens para identificar e autorizar usuários nas requisições da aplicação, permitindo posteriormente implementar diferentes níveis de acesso e proteger recursos que necessitem de autenticação.

Essa etapa ainda está **em desenvolvimento**.

## 🏗️ Arquitetura

O projeto busca aplicar conceitos de **Clean Architecture**, visando separar responsabilidades e facilitar a manutenção e evolução da aplicação.

A estrutura está sendo desenvolvida de forma modular, separando as principais responsabilidades da aplicação em diferentes camadas.

## 🎯 Objetivo

O principal objetivo deste projeto é colocar em prática conhecimentos adquiridos durante os estudos de **C#, .NET e desenvolvimento web**, além de explorar conceitos utilizados em aplicações reais, como:

* APIs REST
* Autenticação e autorização
* JWT
* Banco de dados
* Controle de permissões
* Integração com serviços externos
* Arquitetura de software
* Desenvolvimento de aplicações web

## 🚧 Status do projeto

**Em desenvolvimento**

O projeto possui uma base de desenvolvimento já construída, porém sua implementação foi pausada durante a etapa de desenvolvimento da **autenticação com JWT**.

O desenvolvimento será retomado posteriormente, dando continuidade à implementação da autenticação e das demais funcionalidades planejadas.
